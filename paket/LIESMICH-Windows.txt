NetzWerkstatt – Netzwerke bauen und verstehen
==============================================

So geht's (keine Installation nötig):

1. Diesen Ordner an einen festen Ort kopieren, z. B. in „Dokumente“ oder auf
   einen USB-Stick. (Nicht direkt aus der ZIP-Datei starten!)

2. Doppelklick auf „NetzWerkstatt.exe“.

   Beim ersten Start zeigt Windows evtl. „Der Computer wurde durch Windows
   geschützt“. Dann auf „Weitere Informationen“ und „Trotzdem ausführen“
   klicken. Fragt Windows, ob das Programm im Netzwerk kommunizieren darf,
   bitte „Zugriff zulassen“ wählen.

3. Das Programm prüft alles selbst und öffnet danach die Lehrkraft-Ansicht
   im Browser. Im schwarzen Fenster stehen:
     - die Adresse für die Schülerinnen und Schüler
     - der Raumcode
     - das Lehrer-Passwort
   Das schwarze Fenster während der Stunde offen lassen.

4. In der Lehrkraft-Ansicht auf „Zugang am Beamer zeigen“ klicken.
   Die Schülerinnen und Schüler öffnen die Adresse im Browser (PC oder iPad)
   und melden sich mit Vornamen oder Kürzel und dem Raumcode an.

Beenden: das schwarze Fenster schließen.

Datenschutz
-----------
Alle Daten bleiben auf diesem Rechner in der Datei „netzwerkstatt-daten.json“
in diesem Ordner. Das Programm lädt nichts aus dem Internet und sendet nichts
dorthin. Nach der Unterrichtseinheit kann die Datei einfach gelöscht werden.

Probleme?
---------
- Die Schüler-Geräte erreichen die Adresse nicht:
  Sind alle Geräte im selben Netz (gleiches WLAN/Schulnetz)? Wurde bei der
  Windows-Frage „Zugriff zulassen“ gewählt? Manche Schulnetze trennen
  Schüler- und Lehrergeräte – dann hilft die Schul-IT.
- Der Raumcode ist nach jedem Start ein neuer. Wer schon angemeldet ist,
  arbeitet trotzdem einfach weiter.
- Neues Lehrer-Passwort: Programm beenden, die Datei
  „netzwerkstatt-daten.json“ umbenennen oder löschen, neu starten.
